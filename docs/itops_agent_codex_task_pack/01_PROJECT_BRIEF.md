# Project Brief

## 产品定位

本项目是企业 IT 服务台智能工单处理系统，不是通用聊天机器人，也不是普通知识库问答。

核心定位：

> 面向企业 IT 服务台，构建一个结合 LLM、SOP 检索、Agent Planning、Enterprise Agent Harness、工具网关、审批流和工单状态机的智能工单处理系统。

## 目标用户

### 1. 企业员工

提交 IT 问题，例如账号无法登录、VPN 连不上、需要系统权限。员工希望少填表、少来回沟通、快速知道进度。

### 2. IT 服务台一线工程师

面对大量重复工单。希望 Agent 先完成分诊、补全信息、标准化排查和低风险自动处理，让人工只接管真正复杂或高风险问题。

### 3. IT 管理员 / 审批人 / 系统 Owner

关心 Agent 有没有越权、有没有审计、谁审批了权限、高风险操作有没有被拦截。

## 核心场景

MVP 只做三类工单：

1. 账号锁定 / 登录异常
2. VPN 连接失败
3. 系统权限申请

其他问题统一识别为 UNKNOWN 并升级人工。

## 差异化

### 不是通用问答

通用问答是：

```text
用户提问 -> Agent 回答
```

本项目是：

```text
工单进入 -> 分类 -> 信息补全 -> SOP 匹配 -> Plan 生成 -> Harness 校验 -> 工具执行 / 审批 -> 用户确认 -> 关闭工单
```

### 不是自由 Agent

Agent 只能生成候选计划。候选计划必须经过 Java Enterprise Harness 校验后才能执行。

### 不是简单 RAG

RAG 不是最终目标。SOP 检索用于生成结构化、可校验、可执行的 Plan。

### Java 后端不是 CRUD

Spring Boot 是 Agent Control Plane，负责状态机、工具网关、风险策略、审批流、审计、幂等、异步执行和并发控制。
