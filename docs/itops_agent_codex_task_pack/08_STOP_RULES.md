# Stop Rules

Codex 在以下情况下必须停止编码并返回报告。

## 阶段完成停止

每个阶段满足验收标准后，必须停止，不要自动进入下一阶段。

## 需求越界停止

出现以下情况必须停止并询问：

1. 需要支持第四类工单
2. 需要接真实企业系统
3. 需要多 Agent 协作
4. 需要复杂长期记忆
5. 需要引入未批准中间件
6. 需要改 MVP 主边界

## 安全边界停止

出现以下情况必须停止并报告：

1. Python Agent 需要直接调用 Mock 企业工具
2. Agent 需要绕过 Java Harness
3. WRITE 操作无法生成 idem_key
4. 高风险操作无法进入审批
5. 工具调用无法审计
6. 工单状态无法保证一致

## 技术不确定停止

出现以下情况必须停止并给出选项：

1. 数据库 schema 需要重大重构
2. RabbitMQ 消费语义无法保证
3. Redis 锁与 MySQL 幂等出现冲突
4. LangGraph 状态和 Java 状态机出现事实冲突
5. 测试结果无法达到最低验收线

## 返回格式

停止时必须使用 `templates/EVIDENCE_REPORT_TEMPLATE.md`。
